# Portafolio de Talleres MySQL - Sistema Bancario (BancoDB)

Este repositorio contiene la solución completa, documentada y estandarizada de la serie de **5 talleres de bases de datos relacionales en MySQL**, siguiendo una arquitectura basada en el dominio financiero/bancario y con trazabilidad completa de evidencias visuales.
